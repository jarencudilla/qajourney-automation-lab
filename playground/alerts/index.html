JavaScript Alerts

Native browser dialogs: alert(), confirm(), and prompt(). Handle them correctly in your automation.

Test scenario

Native JS dialogs interrupt browser execution context. Automation tools must handle them explicitly — they do not auto-dismiss.

Test goals
  • Trigger alert → handle dismiss, verify result text
  • Trigger confirm → accept and dismiss separately
  • Trigger prompt → enter value, verify it appears
  • Prompt dismissed → null returned, verify result
Playwright handling
// Accept all page.on('dialog', d => d.accept()); // Fill prompt page.on('dialog', d => d.accept('value'));
