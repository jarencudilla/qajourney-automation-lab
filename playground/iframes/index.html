iFrame Interaction

Practice frame context switching. A common automation hurdle — find elements inside embedded frames.

Test scenario

iFrames create a separate document context. You must switch into the frame before locating any elements inside it.

Test goals
  • Switch to content iframe and read heading text
  • Switch to form iframe and fill the input
  • Click submit inside the frame and verify result
  • Confirm parent-context locators fail on iframe elements
Playwright snippet
const frame = page.frameLocator( '[data-testid="form-iframe"]' ); await frame.locator( '[data-testid="iframe-input"]' ).fill('Hello');
