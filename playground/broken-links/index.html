Broken Link Testing

Valid links, intentional 404s, and redirects. Crawl this page and verify each status code.

Test scenario

Broken links are easy to miss. This page has a mix of working links, known 404s, and a redirect.

Test goals
  • Collect all data-testid links on this page
  • GET each href and assert expected status code
  • Broken links → 404
  • Redirect → 301 or 302
  • External links → 200
Playwright snippet
const links = await page .locator("a[data-testid]").all(); for(const l of links){ const href=await l.getAttribute("href"); const r=await page.request.get(href); console.log(href,r.status()); }
