Dynamic DOM

Elements that appear, disappear, and change at runtime. Test your wait strategies and locator resilience.

Test scenario

Modern UIs are rarely static. This module covers show/hide, delayed appearance, list mutation, and disabled state toggling.

Test goals
  • Show element and assert it is visible
  • Hide element and assert it is not visible
  • Wait for delayed element (3s) with explicit wait
  • Add item to list and verify count increases
  • Remove item and confirm it is gone from DOM
  • Toggle disabled state and verify input is disabled
